
# LIGA4VS4-WEB

Web App oficial de LIGA4VS4.

## Tecnologías
- React
- Vite
- PWA (manifiesto y Service Worker)

## Desarrollo

Instalar dependencias:

    npm install

Iniciar servidor local:

    npm run dev

## Compilación

    npm run build

## Publicación en Cloudflare Pages

- Comando de compilación: `npm run build`
- Directorio de salida: `dist`
- Rama principal: `main`

## Firebase

La aplicación utilizará el mismo proyecto Firebase de LIGA4VS4OFICIAL para compartir autenticación y datos con la aplicación Android.

La configuración de Firebase Web se realizará en una etapa posterior.

No subir claves privadas ni archivos de cuentas de servicio a este repositorio.
